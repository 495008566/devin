About Flask MySQL App

A simple web application with user authentication and CRUD operations.

Features
  • User registration and login functionality
  • Create, read, update, and delete records in the database
  • Simple web interface for interacting with the application
  • Proper error handling and input validation
  • Security features like password hashing
Technologies Used
  • Flask - Web framework
  • SQLAlchemy - ORM for database interactions
  • MySQL - Database
  • Flask-Login - User authentication
  • Flask-WTF - Form handling and validation
  • Bootstrap - Frontend styling
